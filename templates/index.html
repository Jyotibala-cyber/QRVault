How It Works

1
🔐

Encrypt

Select a file and it gets encrypted locally in your browser using AES-256-GCM.

2
📱

Generate QR

A unique QR code and secure link are generated with your chosen expiry settings.

3
📷

Scan

Receiver scans the QR code to access the secure download page.

4
⬇

Download

Receiver downloads the encrypted file which is decrypted locally in their browser.

Security Features

🛡

Client-Side Encryption

Files are encrypted in your browser before upload. The server never sees your plaintext data.

⏱

Expiring Links

Set automatic expiration times from 5 minutes to 24 hours. Server-side enforcement.

📊

Download Limits

Control how many times a file can be downloaded. Prevents unauthorized redistribution.

🚫

Instant Revocation

Revoke access to shared files at any time. Blocked immediately on the server.

🔑

Token-Based Access

No accounts needed. Secure random tokens control all access to shared files.

🔍

Audit Logging

All access attempts are logged for security monitoring and compliance.
